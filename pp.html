Tema 1. PSeInt

Introducción a la Programación

Fundamentos de la programación: algoritmos, pseudocódigo y diagramas de flujo. El profesor proporciona material en PDF (UD 1 Introducción a la programación).

PSeInt es una herramienta educativa para aprender los fundamentos de la programación mediante pseudocódigo en español.

Escribir

Muestra información en pantalla.

Escribir lista_de_expresiones;

Leer

Lee datos introducidos por el usuario desde teclado.

Leer variable1, variable2, ...;

Definir

Declara el tipo de dato de una variable.

Definir variable Como Caracter|Entero|Logico|Real;
  • Caracter: texto
  • Entero: números sin decimales
  • Lógico: verdadero/falso
  • Real: números con decimales

Si-Entonces

Estructura condicional simple.

Si condicion Entonces
	instrucciones

SiNo
	instrucciones

Fin Si

Según

Estructura condicional múltiple (switch-case).

Segun variable_numerica Hacer
	opcion_1: instrucciones
	opcion_2: instrucciones
	De Otro Modo: instrucciones
Fin Segun

Mientras

Bucle que se repite mientras se cumpla una condición.

Mientras condicion Hacer
	instrucciones
Fin Mientras

Repetir

Bucle que se ejecuta al menos una vez hasta que se cumple la condición.

Repetir
    instrucciones
Hasta Que condicion

Para

Bucle con variable de control.

Para variable<-inicio Hasta fin Con Paso paso Hacer
    instrucciones

Tema 2. Python Básico

Variables

En Python no es necesario declarar el tipo de variable; el tipo se asigna dinámicamente. Python es fuertemente tipado y con tipado dinámico, lo que significa que las variables pueden cambiar de tipo durante la ejecución.

  • Los nombres de variables deben empezar con letra o guión bajo
  • No pueden contener espacios ni caracteres especiales
  • Evitar palabras reservadas del lenguaje
  • Python es sensible a mayúsculas/minúsculas
nombre = "Lucia"
edad = 18
altura = 1.65

Tipos de datos

Los tipos de datos básicos en Python son:

TIPO DESCRIPCIÓN
int Números enteros
float Números decimales
str Cadenas de texto
bool Valores lógicos True/False
complex Números con parte imaginaria
list Colección ordenada y mutable
tuple Colección ordenada e inmutable
dict Colección clave-valor

Entrada y salida

Para mostrar información en pantalla se utiliza la función print(). Para leer datos del teclado se utiliza input().

print("Hola mundo")
nombre = input("Introduce tu nombre: ")
print("Te llamas", nombre)

Parámetros de print:

  • sep: modifica el separador entre cadenas (por defecto espacio)
  • end: añade un texto al final de la salida
print("Hola", "mundo", sep="-", end="!\n")
# Salida: Hola-mundo!

Caracteres especiales

CARÁCTER SIGNIFICADO
\n Retorno de línea
\t Tabulador
\\ Diagonal invertida
\" Comilla doble
\' Comilla simple

Tema 3. Control de Flujo

Estructuras if

Las estructuras condicionales permiten ejecutar código según una condición.

if simple

edad = 18
if edad >= 18:
    print("Eres mayor de edad")

if-else

edad = 16
if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")

if-elif-else

nota = 7
if nota >= 9:
    print("Sobresaliente")
elif nota >= 7:
    print("Notable")
elif nota >= 5:
    print("Aprobado")
else:
    print("Suspenso")

Operador ternario

mensaje = "Mayor" if edad >= 18 else "Menor"

La sentencia pass se usa como marcador de posición cuando se requiere sintácticamente una instrucción pero no se desea ejecutar nada.

if edad >= 18:
    pass  # pendiente de implementar

Bucle for

El bucle for recorre cualquier secuencia (listas, cadenas, rangos).

for i in range(5):
    print(i)         # 0, 1, 2, 3, 4

for letra in "Python":
    print(letra)     # P, y, t, h, o, n

Función range()

USO DESCRIPCIÓN
range(n) 0 a n-1
range(inicio, fin) inicio a fin-1
range(inicio, fin, paso) inicio a fin-1 con incremento 
for i in range(2, 10, 2):
    print(i)         # 2, 4, 6, 8

Bucle while

El bucle while ejecuta código mientras se cumpla una condición.

contador = 0
while contador < 5:
    print(contador)
    contador += 1

break y continue

  • break: sale del bucle inmediatamente
  • continue: salta a la siguiente iteración
for i in range(10):
    if i == 3:
        continue     # salta el 3
    if i == 7:
        break        # termina en 7
    print(i)         # 0, 1, 2, 4, 5, 6

Tema 4. Iterables

Listas

Las listas son colecciones ordenadas y mutables de elementos. Se crean con corchetes [].

lista = [1, 2, 3, "texto", True]
lista.append(4)      # Añadir al final
lista.insert(0, "inicio")  # Insertar en posición
lista.remove(2)      # Eliminar primera ocurrencia
lista.pop()          # Eliminar y devolver último
lista.pop(0)         # Eliminar por índice
lista.reverse()      # Invertir orden
lista.sort()         # Ordenar
lista.count(1)       # Contar apariciones
len(lista)           # Longitud
del lista[0]         # Eliminar por índice
lista.clear()        # Vaciar la lista

Comprensión de listas

Forma concisa de crear listas aplicando una operación a cada elemento.

cuadrados = [x**2 for x in range(10)]
pares = [x for x in range(10) if x % 2 == 0]

Tuplas

Las tuplas son colecciones ordenadas e inmutables. Se crean con paréntesis ().

tupla = (1, 2, 3, "texto")
tupla.count(1)       # Contar apariciones
tupla.index(2)       # Índice del elemento
len(tupla)           # Longitud

Las tuplas se pueden unir con el operador + y se pueden desempaquetar en variables.

tupla1 = (1, 2, 3)
tupla2 = (4, 5, 6)
union = tupla1 + tupla2     # (1, 2, 3, 4, 5, 6)

a, b, c = tupla1            # desempaquetado

Diccionarios

Los diccionarios almacenan pares clave-valor. Se crean con llaves {}.

diccionario = {"clave1": "valor1", "clave2": "valor2"}
diccionario["clave1"]        # Acceder a valor
diccionario.get("clave1")    # Acceder seguro (no da error)
diccionario.keys()           # Obtener todas las claves
diccionario.values()         # Obtener todos los valores
diccionario.items()          # Obtener pares clave-valor
diccionario.copy()           # Copia superficial
diccionario.pop("clave1")    # Eliminar clave y devolver valor
diccionario.clear()          # Vaciar el diccionario
len(diccionario)             # Número de pares

# Añadir o modificar
diccionario["nueva"] = "valor"

Se puede recorrer un diccionario con un bucle for:

for clave, valor in diccionario.items():
    print(clave, valor)

Tema 5. Funciones

Funciones

Las funciones permiten organizar y reutilizar código. Se definen con la palabra clave def.

def nombre_funcion(parametros):
    """Documentación de la función"""
    # código
    return resultado

Parámetros y argumentos

Las funciones pueden tener parámetros obligatorios y opcionales.

def saludar(nombre, saludo="Hola"):
    print(f"{saludo}, {nombre}")

saludar("Lucia")             # Hola, Lucia
saludar("Lucia", "Adiós")    # Adiós, Lucia

Parámetros variables (*args)

def suma(*args):
    return sum(args)

resultado = suma(1, 2, 3, 4)  # 10

Retorno múltiple

def operaciones(a, b):
    return a+b, a-b, a*b

suma, resta, prod = operaciones(10, 3)

Funciones anidadas y ámbito de variables

Una función puede definirse dentro de otra función. Las variables locales solo existen dentro de la función donde se definen.

def exterior():
    mensaje = "Hola"
    def interior():
        print(mensaje)
    interior()

globals() y locals()

Las funciones globals() y locals() devuelven diccionarios con las variables globales y locales respectivamente.
