DHCP

El protocolo de configuración dinámica de host (DHCP) proporciona direccionamiento IP automático y demás información a los clientes: dirección IP, máscara de subred, gateway por defecto y dirección de servidor DNS. Está disponible tanto para IPv6 como para IPv4.

Métodos de asignación DHCPv4

  • Asignación manual: el administrador asigna una IPv4 preasignada.
  • Asignación automática: DHCPv4 asigna una IPv4 estática permanentemente.
  • Asignación dinámica: DHCPv4 arrienda una IPv4 por tiempo limitado (el más utilizado).

En Servidor

Seguir las instrucciones del servidor.

En Router (servidor DHCPv4)

Un router Cisco con IOS puede configurarse como servidor DHCPv4:

Router(config)# ip dhcp excluded-address "ip inicio" "ip fin"
Router(config)# ip dhcp excluded-address "ip"
Router(config)# ip dhcp pool "nombre"
Router(dhcp-config)# network "ip pura" "mascara"
Router(dhcp-config)# default-router "gateway"
Router(dhcp-config)# dns-server "ip dns"
Router(dhcp-config)# domain-name "dominio"

Verificación

Router# show running-config | section dhcp
Router# show ip dhcp binding
Router# show ip dhcp server statistics

En un PC cliente: ipconfig /all

Deshabilitar DHCP

Router(config)# no service dhcp

Retransmisión (redes no conectadas directamente)

La dirección IP de ayuda (ip helper-address) permite a un router reenviar difusiones DHCPv4 al servidor DHCPv4, funcionando como retransmisión.

Router(config)# interface ""
Router(config-if)# ip helper-address "ip servidor"

Configuración de router como cliente DHCPv4

Router(config)# interface ""
Router(config-if)# ip address dhcp

OSPF

IPv4

Router(config)# router ospf "n"
Router(config-router)# network "ip pura" "wildcard" area ""

IPv6

Router(config)# ipv6 unicast-routing
Router(config)# interface ""
Router(config-if)# ipv6 ospf "n" area "N"
Router(config)# ipv6 route ospf "n"
Router(config-router)# network "ip pura" area ""
Router(config-router)# router-id 1.1.1.1

DR y BDR

Cuando en un mismo switch hay más de un router conectado, se configuran todos con la misma red.

  • DR → Router con IP mayor o ID mayor
  • BDR → Router con segunda IP mayor o segunda ID mayor

Cambio de prioridad

Router(config)# interface ""
Router(config-if)# ip ospf priority 255

La prioridad es proporcional: 0 < 255

ACL

Orden de prioridad

Dispositivo > Red > Todo

  • Para dispositivo: host 0.0.0.0
  • Para red: 0.0.0.0 0.0.0.0
  • Para todo: any any

ACL Estándar

Se configura en destino. Rango: 1-99 y 1300-1999.

Router(config)# access-list "n" deny|permit "ip origen" "wildcard"
Router(config)# interface ""
Router(config-if)# ip access-group "n" in|out

Configurar Telnet

Router(config)# line vty 0 4
Router(config)# access-class "n" in|out

Acceder y editar ACL

Router(config)# ip access-list standard "n"

ACL Extendida

Se configura en origen. Rango: 100-199 y 2000-2699.

Router(config)# access-list "n" deny|permit ip "ip origen" "wc origen" "ip destino" "wc destino"
Router(config)# interface ""
Router(config-if)# ip access-group "n" in|out

Configurar ping (ICMP)

Router(config)# access-list "n" deny|permit icmp "ip origen" "wc origen" "ip destino" "wc destino"

Configurar Telnet

Router(config)# access-list "n" deny|permit tcp "ip origen" "wc origen" "ip destino" "wc destino" eq telnet

ACL Nombrada

Los nombres pueden contener caracteres alfanuméricos y al menos una letra. Se sugiere mayúsculas.

Estándar

Router(config)# ip access-list "nom" deny|permit "ip origen" "wildcard"
Router(config)# interface ""
Router(config-if)# ip access-group "n" in|out

Extendida

Router(config)# ip access-list "nom" deny|permit ip|icmp|tcp "ip origen" "wc origen" "ip destino" "wc destino"
Router(config)# interface ""
Router(config-if)# ip access-group "n" in|out

Permisos

Permisos normales

Los permisos se representan con 10 caracteres (ej: -rwxr-xr--). El primer carácter indica el tipo:

  • - archivo normal
  • d directorio
  • l enlace simbólico

Los 9 siguientes se agrupan en: usuario (u), grupo (g), otros (o).

VALORPERMISOLETRA
4Lecturar
2Escrituraw
1Ejecuciónx
0Ninguno-

Se suman los números: 754 = usuario(7=rwx) grupo(5=r-x) otros(4=r--)

chmod 754 "fichero"

También con letras (u/g/o/a +/- r/w/x):

chmod u+x "fichero"
chmod go-w "fichero"

Permisos especiales

PERMISOVALOREFECTO
SUID4Ejecuta con privilegios del dueño (s en lugar de x en u)
SGID2Ejecuta con privilegios del grupo (s en lugar de x en g)
Sticky bit1Solo el dueño puede borrar (t en lugar de x en o)
chmod 4755 "fichero"   # SUID
chmod 2755 "fichero"   # SGID
chmod 1777 "directorio" # Sticky bit

ACL (Listas de control de acceso)

Permiten asignar permisos específicos a usuarios o grupos concretos.

getfacl "fichero"                     # Ver ACL
setfacl -m u:usuario:rwx "fichero"    # Asignar permisos a un usuario
setfacl -m g:grupo:rx "fichero"       # Asignar permisos a un grupo
setfacl -x u:usuario "fichero"        # Eliminar ACL

Propietario y grupo

chown "usuario" "fichero"       # Cambiar propietario
chown "usuario":"grupo" "fichero" # Cambiar propietario y grupo
chgrp "grupo" "fichero"          # Cambiar grupo

Máscara de permisos (umask)

Define los permisos por defecto al crear archivos. Se resta de 777 (directorios) o 666 (archivos).

umask 022   # Crea archivos con 644 y directorios con 755

Seguridad de contraseñas

Las contraseñas se almacenan cifradas en /etc/shadow usando MD5 (128 bits) o SHA512 (512 bits). Recomendaciones:

  • Mínimo 8 caracteres
  • Incluir 2 o más caracteres no alfabéticos
  • Evitar palabras comunes o datos personales
  • Cambiar periódicamente

Procesos

Tipos de procesos

  • Procesos del sistema (demonios): permanentes y transitorios. Se inician con el sistema.
  • Procesos de usuario: iniciados por los usuarios.

Jerarquía de procesos

  • Process 0: planificador (scheduler)
  • Process 1 (init/systemd): primer proceso del sistema
  • Process 2 (vhand): gestor de memoria virtual
  • Procesos 3-4 (bdflush, bmapflush): gestión de buffers de disco
