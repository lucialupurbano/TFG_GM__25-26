Tema 1. HTML

Introduccion a HTML

Estructura basica

La estructura de una página HTML tiene un prólogo y un ejemplar.

  • Prólogo:

    Todo documento HTML ha de tener una declaración del tipo de documento donde se le indica al navegador el tipo de documento que se va a iniciar y la versión de HTML utilizada para la codificación del mismo y además le permite interpretarlo correctamente.

    Ejemplar: "<html>" "</html>" En un documento HTML está delimitado por las etiquetas html. El ejemplar puede a su vez dividirse en dos partes

  • Cabecera:

    "<head>" "</head>". Delimitada por las etiquetas head. Contiene la información sobre el título de la página, el autor, palabras clave, etc. Dentro de esta sección es obligatorio definir el título del documento para ello se usan las etiquetas <title>. Está información no se presentará en la ventana del navegador salvo el título que aparecerá en la barra de título de la parte superior.

  • Cuerpo:

    contiene la información que se va a presentar en la pantalla. Está limitado por las etiquetas <body>

<html>
	<head>
    		<title>Titulo</title>
  	</head>
  	<body>
    		"Ejemplo"
  	</body>
</html>

Anclas

Las anclas son enlaces que se vinculan dentro de un mismo documento. Es decir, hacen vínculos para llegar rápidamente de un punto de un documento a otro.

La estructura es parecida a los enlaces.

Estructura:

<a name="ancla">Texto del ancla</a>
<a href="#ancla">Ir al ancla</a>

Cabeceras

Las Cabeceras son los títulos de la pagina web. Al utilizarlas la visualización se hace mas simple y fácil de identificar a simple vista.

En el comando se escribe un numero menor cuanto mayor se quiera hacer el tamaño de la cabecera. Es decir: h1 > h6.

<h1>Cabecera 1</h1>
<h2>Cabecera 2</h2>
<h3>Cabecera 3</h3>
<h4>Cabecera 4</h4>
<h5>Cabecera 5</h5>
<h6>Cabecera 6</h6>

Enlaces

Los enlaces son el equivalente a hipervínculos, gracias a estos se pueden hacer conexiones entre diferentes archivos que no están en el mismo documento. La estructura es parecida a las Anclas, pero a diferencia de estas no están limitados a únicamente un documento.

<a href="https://ejemplo.com">Enlace externo</a>
<a href="pagina.html">Enlace interno</a>

Formato de pagina

Es de la manera de la que se ve la pagina web, podemos configurar el color de fondo y del texto o poner una imagen de fondo. Para poner colores se puede utilizar código hexadecimal RGB (#000000) o el nombre del color en Inglés, (Black), aunque esta ultima puede dar problemas.

Color de fondo

<body bgcolor="#000000">

Color de texto

<body text="#ffffff">

Imagen de fondo

<body background="fondo.jpg">

Formato de texto

Este comando se refiere a las características visuales del texto. O sea, la negrita, la cursiva y el subrayado. Y el salto de párrafo que es el equivalente a un "enter".

Negrita

<b>Texto en negrita</b>

Cursiva

<i>Texto en cursiva</i>

Subrayado

<u>Texto subrayado</u>

Formularios

Esto se utiliza para hacer formularios en los que el usuario interactúa directamente con la pagina web.

Cajas de texto

Caja de texto

<input type="text">

Tipo contraseña

<input type="password">

Area de texto

<textarea>Texto</textarea>

Casillas

Circulares o Radiobutton

Solo se puede seleccionar una opcion

<input type="radio" name="grupo" value="1">

Cuadradas o Checkbox

Se puede seleccionar mas de una opcion

<input type="checkbox" name="opcion" value="1">

Botones

Para enviar datos

<input type="submit" value="Enviar">

Para borrar datos

<input type="reset" value="Borrar">

Asignar funcion

<input type="button" value="Click" onclick="funcion()">

Listas

De un nivel

Solo se muestra una opcion a la vez

<select><option>Opcion 1</option></select>

De varios niveles

Se muestran la cantidad de opciones especificada

<select size="3"><option>Opcion 1</option></select>

Para subir archivos

<input type="file">

Decoraciones

<fieldset><legend>Titulo</legend></fieldset>

Imagenes

Este comando sirve para insertar imágenes. Tienen que ser uno de estos archivos:

  • JPG
  • GIF
  • PNG
<img src="imagen.jpg" alt="descripcion">

Listas

Las listas sirven para colocar un listado de cosas en una lista, para que sea mas visual en lugar de escribir todos los componentes solo separados por una coma.

Ordenadas

<ol><li>Elemento 1</li><li>Elemento 2</li></ol>

Desordenadas

<ul><li>Elemento 1</li><li>Elemento 2</li></ul>

Parrafos

Es de la manera que definimos los párrafos y sus divisiones en los documentos HTML.

Parrafos

<p>Texto del parrafo</p>

Alineaciones

Para colocar el texto, a la izquierda, centrado, derecha y justificado respectivamente.

<p align="left">Izquierda</p>
<p align="center">Centrado</p>
<p align="right">Derecha</p>
<p align="justify">Justificado</p>

Salto de parrafo

<br>

Barra horizontal

<hr>

Tablas

Es el editor de tablas de HTML, es parecido a lo que se puede hacer en word. En las tablas de este lenguaje cada "tr" es una fila y no una columna.

Atributos

<table border="1">

Tabla

<table>
	<tr>
		<td>Celda 1</td>
		<td>Celda 2</td>
  	</tr>
</table>

Combinar celdas

Combinar filas

<td rowspan="2">Texto</td>

Combinar columnas

<td colspan="2">Texto</td>

Tema 2. CSS

Propiedades CSS

"Cascade Style Sheet" o CSS. Lo utilizamos para formatear la arquitectura del sitio.

Para utilizar el CSS hay que vincular un archivo css (ejemplo.css) o escribir el comando de enlace si esta fuera del documento.

Fuera del documento

<link rel="stylesheet" href="style.css">

Dentro del documento

Etiqueta head

<style> ... </style>

Cualquier etiqueta

<div style="propiedad: valor">

Tipos de reglas

ID (#)

Identificador único. Se usa #id { } en CSS y id="nombre" en HTML.

Clase (.)

Reutilizable. Se usa .clase { } en CSS y class="nombre" en HTML.

Etiqueta

Aplica a todas las etiquetas de ese tipo: p { }, div { }.

Prioridad de reglas

ID > Clase > Etiqueta

Para romper la prioridad aplicamos !important.

Propiedades de texto

Propiedades que se le pueden asignar al texto:

  • color: color del texto
  • font-size: tamaño de la fuente
  • font-weight: grosor (bold, normal, lighter)
  • font-style: estilo (normal, italic, oblique)
  • text-decoration: decoración (underline, overline, line-through, none)
  • text-align: alineación (left, center, right, justify)
  • font-family: tipo de letra

Cajas

Son elementos contenedores, dentro pueden tener:

  • Texto
  • Enlaces
  • Imagenes
  • Otros elementos

DIV

El comando <div> ocupa todo el ancho disponible en una pantalla, a no ser que se especifique lo contrario con los comandos de posición o dimensión.

SPAN

El comando <span> ocupa únicamente un determinado numero de palabras (en línea).

Propiedades de cajas

  • border: define el borde (ancho, estilo, color)
  • margin: espacio exterior entre elementos
  • padding: espacio interior entre el borde y el contenido
  • width/height: ancho y alto del elemento
  • position: static, relative, absolute, fixed
  • top/left/right/bottom: coordenadas de posicionamiento

Posicionamiento de cajas

Es la propiedad que nos permite posicionar los elementos dentro de body.

Static

Posicionamiento del flujo del código. Los elementos se posicionan según se definen en el documento HTML.

Absolute

El elemento sale del flujo del código. Le asignamos coordenadas de inserción (top, left, etc.).

Podemos utilizar z-index para modificar el orden de apilamiento. El elemento con mayor z-index está más superficial.

Relative

El elemento no sale del flujo del código, y su posicionamiento es relativo a su posición original.

Podemos utilizar float para que los elementos floten.

Fixed

El elemento se ancla y no se mueve aunque realicemos scroll.

Etiquetas semanticas

Solo aparecen en HTML5, mejoran el posicionamiento de nuestra web en relación a Google.

No son obligatorias

Se consideran elementos de tipo Caja:

  • <header>
  • <nav>
  • <section>
  • <article>
  • <aside>
  • <footer>

Pseudoclases

Definen el estilo de un elemento cuando está en un estado especial.

  • :hover - cuando el ratón pasa por encima
  • :active - cuando se hace clic
  • :focus - cuando tiene el foco (inputs)
  • :visited - enlace ya visitado
  • :first-child - primer hijo de un contenedor
  • :nth-child(n) - enésimo hijo
  • :checked - checkbox/radio seleccionado
  • :disabled - elemento deshabilitado

Flex

Flexbox es un modelo de layout unidimensional que permite distribuir elementos en filas o columnas. Se compone de un contenedor (flex container) y los elementos dentro de él (flex items).

Propiedades del contenedor

  • flex-direction: define la dirección (row, column, row-reverse, column-reverse)
  • flex-wrap: controla si los elementos saltan de línea (nowrap, wrap, wrap-reverse)
  • flex-flow: atajo para flex-direction + flex-wrap
  • justify-content: alineación horizontal (flex-start, flex-end, center, space-between, space-around)
  • align-items: alineación vertical (flex-start, flex-end, center, stretch, baseline)
  • align-content: alineación del contenido cuando hay varias líneas

Propiedades de los elementos

  • order: cambia el orden visual del elemento
  • flex-grow: indica cuánto puede crecer el elemento
  • flex-shrink: indica cuánto puede encogerse el elemento
  • flex-basis: tamaño base del elemento
  • flex: atajo para flex-grow, flex-shrink y flex-basis
.contenedor 
	{
		display: flex;
		flex-direction: row;
		justify-content: center;
		align-items: center;
	}

MediaQuerie

Las media queries permiten aplicar estilos CSS según las características del dispositivo, como el ancho de pantalla, la orientación o el tipo de medio.

Enlace condicional

<link rel="stylesheet" media="screen and (min-width: 768px)" href="pc.css">

Dentro del CSS

@media screen and (max-width: 768px)
	{
		body {background-color: #ffffff;}
	}

Condiciones comunes

  • min-width / max-width: según el ancho de la ventana
  • orientation: portrait o landscape
  • min-device-width / max-device-width: según el ancho del dispositivo

Meta Viewport

Permite controlar el área visible en dispositivos móviles.

<meta name="viewport" content="width=device-width, initial-scale=1">

Acotación de dimensiones

  • max-width: limita el ancho máximo de un elemento
  • min-width: establece un ancho mínimo
  • max-height / min-height: igual para la altura

Transiciones

Las transiciones CSS permiten cambiar suavemente el valor de una propiedad cuando ocurre una acción sobre el elemento, como al hacer hover. Se definen un estado inicial y un estado final.

Propiedades de transition

  • transition-property: propiedad a animar (all o una específica)
  • transition-duration: duración de la transición
  • transition-timing-function: curva de velocidad (linear, ease, ease-in, ease-out, ease-in-out, cubic-bezier)
  • transition-delay: retardo antes de iniciar
.boton
	{
    		background-color: blue;
    		transition: background-color 0.3s ease;
	}
.boton:hover
	{
    		background-color: red;
	}

Keyframes

Los keyframes permiten crear animaciones complejas definiendo puntos intermedios (fotogramas clave) por los que pasa la animación, sin necesidad de una acción externa.

Definición de keyframes

@keyframes mueve
	{
		0% {left: 0;}
		50% {left: 50%;}
		100% {left: 100%;}
	}

Propiedades de animation

  • animation-name: nombre del keyframe
  • animation-duration: duración total
  • animation-timing-function: curva de velocidad (linear, ease, etc.)
  • animation-iteration-count: número de repeticiones (infinite para bucle)
  • animation-direction: normal, reverse, alternate, alternate-reverse
  • animation-play-state: paused o running
  • animation-fill-mode: backwards, forwards, both
  • animation: atajo para todas las anteriores
.elemento
	{
    		animation: 2s linear infinite mueve;
	}
