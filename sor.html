Tema 1. Windows Server

Ediciones WServer

  • Standard: Todos los roles, hasta 4TB RAM y 64 núcleos. Ideal para pymes.
  • Datacenter: Hasta 4TB RAM y 640 núcleos. Máquinas virtuales ilimitadas. Grandes empresas.
  • Foundation: Máx 15 usuarios. Solo DHCP, DNS y servidor de ficheros. Grupo de trabajo.
  • Essential: AD limitado a 1 DC. Hasta 25 usuarios y 50 máquinas. 64GB RAM.

Roles

Servicios que aportan funciones suplementarias a los clientes:

  • AD DS: Active Directory Domain Service - autenticación de cuentas
  • AD CS: Certificate Service - certificados digitales
  • DHCP: Distribución de configuraciones de red
  • DNS: Resolución de nombres
  • Impresión: Impresoras en red y grupos de impresión

Características

Funcionalidades extra para configuración del servidor:

  • Backup: Copias de seguridad del servidor
  • Clúster: Servidores funcionan conjuntamente para alta disponibilidad
  • Balanceo de carga: Distribuir tráfico entre servidores
  • Interfaz gráfica: GUI para gestión

Servidor Core

Instalación sin interfaz gráfica, solo comandos (PowerShell). Menos actualizaciones y recursos. La GUI se puede instalar como característica.

Consolas

Permiten gestionar, administrar y configurar los servicios:

  • Server Manager: Añadir/quitar roles, gestionar servidores
  • Usuarios y Equipos AD
  • DNS
  • DHCP

Tema 2. Active Directory

Objetivo

AD abarca cuentas para la autentificación de equipos y usuarios. Facilita la gestión, administración y configuraciones masivas. Un usuario de dominio puede validarse en cualquier máquina del dominio con permiso.

Componentes de AD

Físicos

  • DC (Controlador de dominio): Servidor con AD DS. Al menos 1 por dominio.
  • BBDD y SYSVOL: ntds.dit (base de datos), SYSVOL (políticas de grupo)
  • GC (Catálogo Global): Búsquedas rápidas en el bosque

Lógicos

  • Bosque: Contenedor de mayor rango
  • Árbol de dominio: Espacio de nombres DNS contiguo
  • Dominio: Límite administrativo para usuarios y equipos
  • OU (Unidad Organizativa): Contenedor para delegación y GPOs

Particiones de BBDD

  • Configuración: topología del AD
  • Esquema: atributos y clases
  • Dominio: objetos del dominio
  • DNS: zonas y registros DNS

Maestros de Operación FSMO

5 roles en un bosque de AD:

  • Maestro de Esquema: 1 por bosque, permisos de escritura del esquema
  • Maestro de Nomenclatura: 1 por bosque, añadir/eliminar dominios
  • Maestro RID: 1 por dominio, asigna bloques de 500 SID
  • Maestro de Infraestructura: 1 por dominio, vigila objetos ajenos
  • Maestro PDC: 1 por dominio, sincronización de reloj y contraseñas

Comando: netdom query fsmo

Papelera de Reciclaje

Deshabilitada por defecto. Se activa desde el Centro de Administración de AD. Crea la carpeta "Deleted Objects" para recuperar eliminaciones accidentales. Una vez activada, permanente.

Tema 3. Administración de objetos de AD

Consolas

  • Server Manager: Gestión general del servidor
  • Usuarios y Equipos AD: Crear/eliminar/delegar objetos
  • Sitios y Servicios AD: Replicación entre sitios
  • Dominios y Confianzas: Relaciones de confianza
  • Centro de Administración AD: Gestión avanzada, papelera, PSO

Administración de Cuentas de Usuario

  • Nombre único en el dominio/bosque
  • Atributos obligatorios: nombre y contraseña
  • Perfil móvil: Ruta \\Servidor\PerfilUsuario\%username%
  • Miembro de grupos para asignar permisos

Administración de Grupos

Tipos

  • Distribución: Sin SID, solo para correo
  • Seguridad: Con SID, para permisos

Ámbitos

  • Local: Solo en la máquina local
  • Dominio Local (DL): Permisos en el dominio
  • Global: Miembros del mismo dominio, permisos en todo el bosque
  • Universal: Miembros de cualquier dominio, se replica en GC

Estrategia IGDLA

Identidades → Grupos Globales → Grupos Dominio Local → ACL

Grupos por defecto

  • Domain Admins: Administradores de dominio
  • Server Operators: Administrar servidores
  • Account Operators: Gestión de cuentas
  • Backup Operators: Copias de seguridad
  • Print Operators: Gestión de impresoras

Administración de Cuentas de Máquina

  • Se crean en Consola Usuarios y Equipos → Nuevo → Equipo
  • Al unir un equipo al dominio se crea la cuenta
  • Por defecto en carpeta Computers (no es OU, no admite GPOs)
  • Si un equipo está apagado >30 días, se rompe el canal seguro

Canal Seguro

Comprobación y reparación con PowerShell:

Test-ComputerSecureChannel
Reset-ComputerMachinePassword

Delegación Administrativa

Permite delegar permisos sobre OUs. Se aplica sobre la OU → Delegar Control. Se añade el grupo y se marcan tareas. La denegación tiene prioridad sobre permitir. Los explícitos sobre los heredados.

PowerShell

# Usuarios
New-ADUser -Name -Surname -GivenName -Path -Enabled
Set-ADUser
Remove-ADUser
Get-ADUser

# Grupos
New-ADGroup -Name -GroupScope -GroupCategory -Path
Set-ADGroup
Remove-ADGroup

# Equipos
New-ADComputer -Name -Path
Set-ADComputer
Remove-ADComputer

# OU
New-ADOrganizationalUnit -Name -Path
Set-ADOrganizationalUnit
Remove-ADOrganizationalUnit

Tema 4. Servicio DHCP

Ventajas

  • Automatiza configuración de red
  • Reduce errores, evita IP duplicadas
  • Útil para usuarios itinerantes
  • Facilita monitorización

Asignación de IP dinámica

Intercambio de 4 paquetes:

  1. DHCPDISCOVER: Cliente busca servidor DHCP (broadcast)
  2. DHCPOFFER: Servidor ofrece configuración
  3. DHCPREQUEST: Cliente acepta la oferta
  4. DHCPACK: Servidor confirma y registra

Configuración de DHCP

  • Ámbito (scope): Rango de IPs a asignar
  • Exclusiones: IPs del ámbito que no se asignan
  • Reservas: IP fija por MAC (impresoras, teléfonos IP)
  • Filtros: Permitir/Denegar equipos por MAC

Base de datos: C:\Windows\System32\dhcp\dhcp.mdb. Copia automática cada hora en backup.

Tema 5. Implementación de DNS

Servicio DNS

Resuelve nombres a IP y viceversa. FQDN = Hostname + sufijo DNS (máx 256 caracteres). Estructura jerárquica: raíz (.) → TLD (.com, .es) → dominio → subdominios → host.

Tipos de Registros

  • A: Nombre → IPv4
  • AAAA: Nombre → IPv6
  • PTR: IP → Nombre
  • CNAME: Alias
  • SOA: Información general de la zona (1 por zona)
  • NS: Servidores de nombres
  • MX: Servidores de correo

Consultas DNS

  • Iterativas: El servidor consulta a otros servidores paso a paso
  • Recursivas: El servidor se encarga de toda la resolución mediante reenviador condicional

Zonas de DNS

  • Directa: A (nombre → IP)
  • Inversa: PTR (IP → nombre)
  • Primaria: Lectura/escritura. 1 por zona
  • Secundaria: Copia solo lectura
  • Stub: Copia parcial (solo registros necesarios)
  • AD Integrated: Integrada en AD, se replica automáticamente

Comandos de DNS

nslookup              # Buscar registros DNS
ipconfig /flushdns    # Borrar caché DNS
ipconfig /displaydns  # Mostrar caché DNS

Tema 6. Administración de Servidores de Archivos

Permisos NTFS

Estándar

  • Control Total: Todo, incluyendo permisos y propiedad
  • Modificar: Leer, escribir, eliminar, crear y ejecutar
  • Leer y Ejecutar: Leer archivos y ejecutar programas
  • Lectura: Leer archivos
  • Escritura: Modificar y escribir
  • Mostrar contenido: Ver contenido de carpeta

Avanzados

  • Atravesar carpeta/ejecutar archivo
  • Crear archivos/escribir datos
  • Eliminar subcarpetas y archivos
  • Cambiar permisos
  • Tomar posesión

Herencia habilitada por defecto. Explícitos tienen prioridad sobre heredados.

Recursos Compartidos

Acceso directo a recursos en servidor mediante ruta UNC: \\SERVER\Share. Se puede limitar acceso con permisos NTFS.

Instantáneas (Shadow Copies)

Imágenes estáticas de archivos compartidos. Permiten restaurar versiones anteriores. Por defecto L-V 12:00 y 7:00. No son alternativa al backup (mismo disco).

Impresoras en Red

Rol: Servicios de impresión y documentos. Los clientes envían trabajos al servidor. Grupo de impresión: Varias impresoras físicas como una lógica (balanceo). Mismo controlador y formato.

Tema 7. Directivas de Grupo (GPO)

Características

Gestión masiva, rápida y centralizada desde el DC.

  • Configuración de usuario (persigue al usuario) o equipo (afecta a la máquina)
  • Directivas: Configuración de software, Windows, plantillas administrativas
  • Preferencias: No obligatorias, usuario puede modificarlas. No se eliminan automáticamente
  • Se vinculan a contenedores (OU mínimo)

Almacenamiento de GPOs

  • GPT (Group Policy Template): Parámetros de seguridad, scripts. Extensiones .adm/.admx. En SYSVOL
  • GPC (Group Policy Container): En BBDD de AD. Control de versiones (gpt.ini). Se comprueba cada 90-120 min

Almacén central

Plantillas .admx en SYSVOL del DC: C:\SYSVOL\{domain name}\Policies

Implementación

Delegación: Domain Admins, Enterprise Admins, Creator Owner, System. Usuarios autenticados tienen lectura/aplicación.

Procesamiento: Local → Site → Domain → OU. Refresco cada 90-120 min (seguridad cada 16h). Comando: gpupdate /force.

Directivas predeterminadas: Default Domain Policy (raíz del dominio) y Default Domain Controllers Policy (OU Domain Controllers).

Securización con GPO

  • Políticas de contraseña (histórico, vigencia, longitud, complejidad)
  • Políticas de bloqueo (intentos y tiempos)
  • Kerberos (sincronización horaria)
  • Directivas de auditoría
  • Restricciones de software (reglas por hash, ruta, certificado, zona)
  • AppLocker: Control avanzado de aplicaciones
